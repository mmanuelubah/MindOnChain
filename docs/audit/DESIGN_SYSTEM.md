# Alltech Solutions design system

Status: **in use** on the home page, header, footer and search (Phase 7). Other pages move onto it in Phase 8. The source of truth is `assets/css/alltech.css`; this file explains it.

Every rule below has a reason tied to this business. A change that cannot give a reason like these does not go in.

## Direction

Cartoonish, green, electronic. Alltech's work happens inside car electronics, so the site borrows from the tools of that trade: an oscilloscope screen, a CAN bus trace, pixel type like a scan tool's display. Vox-style editorial principles still run the content: a plain headline that says what the page is, a short explainer, clear section labels.

Owner decisions (2026-10-29): green instead of the earlier danfo yellow; colours close to MyEasyAgents (the owner's other company); a green logo and favicon; cyberpunk, pixel-art feel; the CAN oscilloscope on the home page. The yellow version is kept at the git tag `alltech-yellow-2026-10-29`.

**`.screen`** is the always-dark band (home hero, parts panel, footer). It redeclares the tokens with the dark values, so everything inside works in both themes without special cases.

## Type

| Role | Family | Rule |
| --- | --- | --- |
| Display, section heads, labels, stickers | Pixelify Sans (SIL OFL) | **Words only.** Its B/8, 5/S and 0/O look alike, so part numbers and codes never use it. |
| Body and interface | Archivo (SIL OFL) | |
| Long reading (posts, book notes) | Source Serif 4 (SIL OFL) | Loaded only where used. |
| Part numbers, codes, scope readouts | System monospace | No download. |

Scale (rem, follows the reader's text size): 0.8125, 0.9375, 1.0625 (body), 1.3125, 1.625, clamp(2–2.5), clamp(2.5–4.25).

## Shape

- Spacing scale: 4, 8, 12, 16, 24, 32, 48, 64, 96 (`--s-1` to `--s-9`).
- Outlines: 3px (`--line`), section rules 4px (`--rule`). This is the cartoon line.
- Corners: square, with **pixel-stepped corners** (`--step: 4px`) on buttons, tool buttons, brand chips and stickers. The step is removed on keyboard focus so the focus ring is never clipped.
- Shadows: none. The only glow is the phosphor glow on the oscilloscope trace, which is part of the illustration.
- Breakpoints: 400 (stacked wordmark), 480, 640, 900.

## Components

- **Wordmark:** green logo tile + "Alltech" + "Solutions" on a brand bar. Stacks on phones narrower than 400px.
- **NEPA bulb:** the theme switch. Lights on = light mode, says "Up NEPA!"; off = dark, groans. `aria-pressed` and a text label carry the state.
- **Oscilloscope:** `layouts/partials/can-scope.html`, generated by `tools/can_scope.py` from a real CAN 2.0A frame (ID 7DF, OBD-II engine RPM request, CRC-15 and bit stuffing checked). Scrolls sideways inside its frame on phones. The beam sweep stops under reduced motion.
- **Sticker, speech bubble, section head, buttons, brand chips, rows, steps, search** as in `alltech.css`.

## Voice

Plain, specific, first-hand. Name the module, the car and the job. No unverified promises: no warranty (owner: none), prices on request, delivery only "ask". Banned: the skill's seed list plus "Your Vehicle. Our Expertise.", "Quality Guaranteed", "all in one place", "Learn More", "Check back soon", "elegant", "seamlessly".

## Navigation policy

Header: wordmark (home) | Database | Guides | Parts | Writing | About | Search | bulb. Footer: contact (WhatsApp, email), LinkedIn, GitHub, X, Colophon, RSS. At most one contact route in page content plus the footer. External URLs live in `hugo.toml`.
